Config Wizard

Context
Juniper / HPE Mist, 2025 to now
Role
Designed and built
Stack
Python, PyQt6, REST APIs, PyInstaller

Recreate an access point's WLAN configuration in another Mist org or site, without retyping it.

A desktop tool that reads the configuration from a support bundle or live from the device, lets you review and complete each WLAN, then recreates it through the Mist REST API. It has a dry-run mode, an audit log and HTML reports, and ships as a single executable.

Disaster-recovery validation

Context
Juniper / HPE Mist, 2025 to now
Role
Validation and escalation
Stack
GCP, AWS, Kafka telemetry, REST APIs, Linux
Status
Internal work, no public detail

Do cloud failover changes behave for devices in the field?

I validated the GCP Frankfurt DR migration and the AWS UAE outage failover. Each change ran through three stages, staging, UI integration and production, while I checked access-point claim behaviour. Tracing connectivity and re-claim problems across the data path was most of the work.

Make microservice autoscaling respond to cold starts and traffic spikes.

A configurable per-service resource broker that drives two Kubernetes mechanisms: the Horizontal Pod Autoscaler for pods and the Cluster Autoscaler for nodes.

WeedYOLO-MS

Context
B.Tech capstone, 2025
Role
Model design and ablation
Stack
PyTorch, YOLOv9, Swin Transformer, CBAM
Status

A weed detector accurate enough to be useful and small enough for the edge.

Hybrid architectures that fuse a Swin Transformer backbone with CBAM-style attention on YOLOv9, then an ablation across fusion strategies, trained and evaluated on the public CottonWeedDet12 dataset.

0.855Precision
0.855mAP@0.50
3.56MParameters
15.6GFLOPs

Figures are the report's stated optimal model, CBAM || Swin, after 200 epochs: precision 0.855, recall 0.785, mAP@0.50:0.95 0.785.
